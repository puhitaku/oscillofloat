# コンセプト
「客がページを開き、線画をタッチで描き、送信ボタンを押すと、インターネットを通じて線画がアップロードされ、Oscilloshape によってオシロスコープにその線画が描かれる」という体験を作りたい。

現在見えている "oscilloshape" はオシロスコープのリサジュー図形モードで描ける信号を生成し DAC に流すソフトウェア、"oscillofloat" は Oscilloshape と組み合わせて前述のデモを作り上げるための別のリポジトリである。

以下のユーザーストーリー、構成、共通の要件について吟味し、プランを立て、不明な点があれば質問にまとめて私に聞くこと。その後、実装に入ること。

# ユーザーストーリー
以下のストーリーを満足する実装を与えること。

## 一般ユーザー
  - `osc.puhitaku.com/` を開くと、画面中央のキャンバスと画面上のツールバーが現れる
  - オシロの画面に映す線画がタッチとスワイプで描ける
    - 線の量はとりあえず無制限
    - 一本でも線が描かれた状態でページを遷移しようとするとブラウザ標準の警告が出る
  - 線を消しゴムで消せる
  - 線画をアップロードできる
  - ツールバー左側: ハンバーガーメニュー
    - 過去にアップロードしていて、セッション ID で紐付いた絵が消せる「アップロードした絵の消去…」
    - プロジェクターで映す映像が出せる「浮遊」ページ (`/float`) へ飛ぶ「浮遊デモを見る」リンク
  - ツールバー右側: ペン、消しゴム大小、（セパレーター）、Undo、Redo、（セパレーター）、送信
    - 送信のみ確認ダイアログが挟まる

## 浮遊デモ表示プロジェクター
  - `/float` を開くと、Web フロントに以下の動きが実装された浮遊デモが表示できる
  - ひとまず黒背景
  - プリセット線画、これまでに送信された線画のすべてが出現と消滅を繰り返している
    - 出現と消滅のアニメーションは「フェードイン + ease-out で拡大」と「フェードアウト + ease-in で縮小」だけでひとまずOK
    - ゆっくりと等速直線移動と回転をしながら出現、しばらく漂ったのち消滅でひとまずOK
  - プリセット線画は oscilloshape に登録されたものを使い、フロントに embed する
  - 絵の取得については、後述の `/ws` ですべて行う

## Admin
  - `/admin` を開くと、Passkey でログインできる
  - 管理画面として、絵を一覧で表示できる
  - 絵を選んで削除できる

## Oscilloshape
  - `/ws` を WebSocket で開くと、リアルタイム API が利用できる
    - 絵のデータ本体を含む新規の絵の通知
    - 削除された絵の通知（フロントに忘れさせる用）
      - フロントは削除通知が来た絵に内部でフラグを立て、次に新規の絵が来たりと一覧に変更が加わるか内容を参照する際にフラグの立ったものを削除する
    - 絵の一覧取得
    - 絵を1つまたは複数取得
  - 新規の絵の表示については、今はとりあえずアニメーション等なしでただ通知が来たもを表示するだけとし、自動で別の絵をスライドショーする等はしない

# バックエンドの構成
AWS を利用する。同時接続者は高々10人程度のため、コスト低減に振る。
  - Domain: osc.puhitaku.com（Route 53 にある puhitaku.com を使う）
    - DNS は反映に独特の時間差があるため、CloudFormation を使用せず awscli で直接設定する
  - IaC: CloudFormation
  - DB: EC2 (SQLite + Litestream) + S3
    - DB の内容は CloudFormation スタックの有無にかかわらず永続化したいので awscli で直接バケットを用意する
  - Backend: Go + EC2 + CloudFront
  - Frontend: S3 + CloudFront
  - Auth: Cognito
    - 管理者ページへのログインに使用
    - フロントからは新規ユーザー登録を行わない
    - CloudFormation でのデプロイ後、指定のメールアドレスでユーザーを作成し、メールから Passkey 登録へ誘導する
    - 「Passkey のみ」で認証し、設定が必須のパスワードは長いものをランダムに生成する

  - フロントエンドで表示される文字列はすべて日本語とする
  - ピクトグラムを使用し、直感的な UI にすること
